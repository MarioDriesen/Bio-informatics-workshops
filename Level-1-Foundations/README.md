# Level 1 - Foundations

This level introduces the skills required for most bioinformatics analyses.
Participants will learn how to work in a Linux environment, navigate the command line, and prepare an environment for running bioinformatics tools.

Whenever possible, we also link to high-quality free online tutorials and learning resources.

## Learning Objectives

After completing this level, you should be able to:

- Understand why Linux is widely used in bioinformatics.
- Access a Linux environment locally or remotely.
- Navigate the Linux file system.
- Create, modify, copy, and delete files and folders.
- View and search text files from the command line.
- Understand the basics of shell scripting.
- Work comfortably in preparation for more advanced bioinformatics workshops.
