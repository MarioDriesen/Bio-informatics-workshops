# Bioinformatics Workshops

A collection of self-guided workshops covering practical bioinformatics skills.
Made by a biologist for every-one :) 
The idea is to make one central educational place with some well developed exercises and examples
and a folder containing a list of useful tools we compile over the years. 

## Roadmap

### Level 1 - Foundations

1. Introduction to Linux & GitHub Codespaces
   - Basic command line
   - File navigation
   - Running analyses in Codespaces

### Level 2 - Sequence Data

2. From Genes to FASTQ
   - Sequencing basics
   - FASTQ format
   - Quality control

### Level 3 - Analysis

3. How to analyse genetic data
   - Mapping
   - Variant calling
   - Assembly

### Level 4 - Workflows

4. Nextflow
   - Why workflows matter
   - Running existing pipelines
   - Building simple pipelines
